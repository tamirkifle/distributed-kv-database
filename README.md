# Distributed Key-Value Store

A learning project implementing distributed systems concepts through incremental commits.

## Project Structure

```
distributed-kv-store/
├── src/main/java/com/distributed/kv/  # Core implementation
└── src/test/java/com/distributed/kv/  # Tests demonstrating behavior
```

## Learning Path

- **Milestone 1**: CAP Theorem & Basic KV Store
- **Milestone 2**: Leader-Follower Pattern
- **Milestone 3**: Quorum Systems
- **Milestone 4**: Leaderless Architecture
- **Milestone 5**: Network Partitions
- **Milestone 6**: Consistency Testing
- **Milestone 7**: Performance Patterns

## Build & Run

```bash
mvn clean compile
mvn test
```
